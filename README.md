# Welcome! 
This is a place for me to showcase the outputs of AI agents that were created with the help of Claude AI and a pro subscription. 

This process began as a concern that Product Owners and Product Managers would eventually be removed from the software development process completely. So, I wanted to flip the script a bit an help others understand the need for product management and the need for engineers in the same teams, working toward the same goals...solving the business problems in creative ways.
